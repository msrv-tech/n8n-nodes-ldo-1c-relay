## Метод и результаты

Настоящие ноды выполнялись в активных workflow через n8n Public API и защищённые
webhook; fixtures/assertions/cleanup — через зарегистрированный bridge UNF2.
Проверены все ранее доступные standalone-действия и две новые операции поиска.

- Search Documents → Get Document Fields: ID берётся из результата выражением.
- Строковый номер с ведущим нулём, календарная дата и локально настроенная организация.
- Search Catalog Items → Get Catalog Fields: ID также берётся выражением.
- Наименование и фильтр taxNumber, отображённый локальной политикой на ИНН.
  В общем обработчике названия этого реквизита и справочника отсутствуют.
- Seek-пагинация, ограниченный Return All, корректная граница календарного дня.
- Пустой List возвращает ноль items; Single отклоняет неоднозначность.
- Неподдерживаемый фильтр, короткий запрос, неверная дата, широкий период
  и изменённый курсор отклоняются.
- Остальной полный набор: документы/справочники/ссылки/процессы/события/PDF/Wait/
  подключения/повторы/AI — passed в применимых queue/direct режимах.

Тестовый webhook настроен с top-level responseData=allEntries, поэтому сравнивается
весь набор выходных items, а не только первая строка. Подмена курсора проверяет
и подпись/контекст, и полный канонический JSON: parser 1С сам по себе допускает
дописанные символы после объекта, поэтому добавлена строгая проверка.

## Перенос и границы

CORE получил универсальный серверный модуль и элементы/методы формы поиска.
Настройки подключения и остальная компоновка CORE сохранены. Права поиска
отдельны от write-grants; дополнительные поля определяются только локальным
администратором и проверяются по стандартным/прикладным реквизитам метаданных.

MSRV: обновлены JSON-схема, validator команд и безопасная фильтрация capabilities.
API полный unit-набор прошёл: **120 tests**, включая 14 search-contract tests
с проверками некорректных JSON-типов. Живой MSRV-транспорт новых операций не запускался.
Единственный not-run полного standalone-набора — MSRV Confirm PDF Delivery.

Другие конфигурации, Fresh и n8n Cloud не объявляются проверенными по результату
УНФ. Полный прогон не проверяет scheduler: bridge запускает штатный polling.
Все изменения локальны; публикация npm/CFE и перенос в адаптеры не выполнялись.
